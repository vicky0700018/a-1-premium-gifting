# Build a Premium E-Commerce Website for A-1 Dry Fruits

Create a complete, modern, premium and responsive **E-Commerce website** for **A-1 Dry Fruits**, a trusted dry fruits, nuts, seeds, spices and gifting business based in South Mumbai.

## IMPORTANT TECHNOLOGY REQUIREMENTS

Use ONLY:

* React
* Vite
* Tailwind CSS

Do NOT use any other technology, framework, UI library, component library, CSS framework, backend technology, database, authentication service, API, or third-party library.

### Strictly DO NOT use:

* Next.js
* Node/Express backend
* Firebase
* Supabase
* MongoDB
* PostgreSQL
* MySQL
* Any database
* Any external authentication service
* Material UI
* Bootstrap
* Shadcn
* Ant Design
* Redux
* Any other UI/component/library dependency

The entire project must work as a **frontend-only React + Vite + Tailwind CSS application**.

Use **Mock Data / local static data only**.

All products, categories, orders, customers, banners, coupons, reviews, etc. should be represented using local mock data / JavaScript objects or arrays.
